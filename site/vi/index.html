Mã nguồn mở · Backup & restore cho MySQL, MariaDB và PostgreSQL

Backup không khóa database. Khôi phục đến đúng giây bạn cần.

DumpCat là một file chạy duy nhất kèm giao diện web. Nó lên lịch backup, nén và mã hóa, đẩy bản sao lên S3, Google Drive, OneDrive hay SFTP, tự kiểm tra toàn vẹn và đưa dữ liệu về khi bạn cần. Chạy trên Linux lẫn Windows, không cần internet.

Cài đặt

Chạy được sau một phút

Một lệnh trên Linux, tải về và bấm đúp trên Windows. Bộ cài tạo service tự chạy cùng máy và cài luôn công cụ backup khớp với version database; giao diện web có sẵn trong một file duy nhất.

Trên server Linux, dán lệnh này rồi bấm Enter:

bash
curl -fsSL https://dumpcat.cc/install.sh | sudo sh

Lệnh tải bản mới nhất, kiểm tra checksum rồi cài vào /opt/dumpcat thành service systemd, kèm rclone, MySQL/MariaDB client, mariabackup hoặc XtraBackup đúng version, và mydumper nếu repo có; --postgres 16 cài thêm công cụ client PostgreSQL 16. Tùy chọn đặt sau sh -s --: --port 9090, --listen 127.0.0.1, --tls-auto.

  1. Tải file .zip Tải cho Windows 1.5.0
  2. Giải nén: chuột phải vào file, chọn Extract All.
  3. Bấm đúp Install DumpCat rồi chọn Yes. Trình duyệt tự mở DumpCat, cửa sổ cài đặt hiện mã thiết lập.

Windows 10 / 11 hoặc Windows Server 2016+ 64-bit, chạy như Windows service. Quen PowerShell? Chạy irm https://dumpcat.cc/install.ps1 | iex trong PowerShell (Administrator). Không có mydumper và XtraBackup cho MySQL; database hàng trăm GB nên chạy DumpCat trên Linux.

Chưa quen dòng lệnh? Xem hướng dẫn từng bước, có cả cách xử lý khi gặp lỗi.

Mất máy chạy DumpCat? Cài bản mới, thêm lại nơi lưu, bấm Import backup catalog là thấy lại toàn bộ backup. Không có DumpCat vẫn restore được bằng age, zstd và mysql hoặc pg_restore.

Kết nối

Database không mở port? Vẫn backup được

Khi server backup không kết nối thẳng được tới database, vì firewall, NAT hay database chỉ nghe trên 127.0.0.1, hãy để chính server database kết nối ra DumpCat. Có hai cách, cả hai đều không cần mở port nào trên server database. Backup, restore và khôi phục theo thời điểm chạy y như kết nối trực tiếp.

Hợp khi
Đội đã quen WireGuard, hoặc một gateway dẫn tới cả mạng database

Đường kết nối do server database mở ra; dữ liệu đi hai chiều bên trong nó. Backup vật lý (XtraBackup / MariaBackup) chạy được qua agent khi agent bật --allow-physical; qua WireGuard thì vẫn cần cài DumpCat ngay trên server database.

Vận hành

Những việc bạn khỏi phải tự viết script

Tất cả có sẵn trong DumpCat và được bật, chỉnh ngay trên giao diện web.

Mã hóa trước khi upload
age (ChaCha20-Poly1305 + scrypt) chạy trên server của bạn, nhà cung cấp cloud không đọc được dữ liệu.
Kiểm tra toàn vẹn
SHA-256 cho từng file. Verify đọc lại, giải mã, giải nén và tìm dòng Dump completed.
Retention kiểu GFS
Giữ N bản, N ngày, bản cuối mỗi ngày, tuần, tháng. Chuỗi incremental chỉ bị xóa cùng bản full gốc.
Restore cẩn thận
Thử giải mã mọi file trước khi DROP database. Restore sang tên mới, hoặc sang server và phiên bản khác (MySQL 8 ↔ MariaDB, PostgreSQL 15 → 16).
Tài khoản và phân quyền
admin, operator, viewer. 2FA bằng TOTP, API token, nhật ký thao tác, khóa sau nhiều lần đăng nhập sai.
Thông báo
Email, Telegram, Slack, Discord và Webhook ký HMAC, khi lỗi hoặc khi thành công.
Database sau firewall
Agent trên server database tự kết nối ra DumpCat qua HTTPS, hoặc dùng WireGuard tích hợp. Không cần mở port nào tới database.
Tự cập nhật
dumpcat update kiểm tra SHA-256, backup cấu hình, chờ backup đang chạy xong và tự rollback nếu lỗi.

Mã nguồn mở

Miễn phí, mã nguồn mở, dữ liệu vẫn là của bạn

DumpCat phát hành theo giấy phép Apache-2.0. Không cần tài khoản, không license key, không có bản trả phí khóa bớt tính năng: mọi thứ trên trang này đều nằm trong bản bạn tải về.

Giấy phép Apache-2.0
Dùng cho cá nhân hay doanh nghiệp, sửa và phân phối lại đều được. Toàn văn giấy phép nằm trong LICENSE.
Không telemetry
DumpCat không gửi dữ liệu sử dụng đi đâu cả. Việc duy nhất nó tự gọi ra ngoài là mỗi ngày đọc latest.json một lần để báo bản mới, và bạn tắt được trong Settings.
Không qua máy chủ trung gian
Backup, mật khẩu database và khóa mã hóa chỉ đi từ server của bạn tới nơi lưu trữ do bạn chọn.
Bản phát hành có ký
Mỗi bản cập nhật được ký ed25519 và kiểm tra SHA-256 trước khi cài. Muốn tự build thì chỉ cần Go.

Build từ mã nguồn

bash
git clone https://github.com/theweakestharrison/DumpCat.git
cd DumpCat
go build -o dumpcat ./cmd/dumpcat

Báo lỗi, gửi pull request hay dịch tài liệu đều được chào đón, xem CONTRIBUTING.md. Lỗi bảo mật xin báo riêng theo SECURITY.md.
