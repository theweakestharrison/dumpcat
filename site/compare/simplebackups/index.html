DumpCat vs SimpleBackups

SimpleBackups is a hosted service that schedules and monitors backups of servers, databases and storage from its own infrastructure. DumpCat is a free, open-source backup manager that you run next to your database. Here is how they compare for MySQL and MariaDB.

Choose SimpleBackups if

  • You want nothing to install or keep running: SimpleBackups schedules and monitors from its own infrastructure, so you still get an alert when your server is down.
  • You back up several engines (PostgreSQL, MongoDB, Redis) or managed databases such as PlanetScale from one dashboard.
  • You need compliance paperwork such as ISO 27001, SSO or an SLA.

Choose DumpCat if

  • You need point-in-time recovery: DumpCat archives binlogs continuously and restores to a given second or just before a GTID.
  • Your databases are large: hot physical backups with XtraBackup / MariaBackup, incrementals, and no per-plan limits on jobs, database size or storage.
  • You want restores from the web UI, including into a new database name to compare before switching.
  • Credentials and data must stay inside your own infrastructure, or the server has no internet access.
  • You would rather not pay per job: DumpCat is free and open source.

Switching from SimpleBackups

  1. Install DumpCat on the database server, or on a machine that can reach it.
  2. Add the storage you already use with SimpleBackups (S3, B2, Google Drive…) as a DumpCat storage, in a new folder.
  3. Recreate each job with its databases, schedule, encryption and retention, then run it once and check the integrity result.
  4. Keep your SimpleBackups backups until DumpCat's retention covers the same period, then cancel the plan.
