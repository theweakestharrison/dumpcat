Mã nguồn mở · Backup & restore cho MySQL và MariaDB

Backup không khóa database. Khôi phục đến đúng giây bạn cần.

DumpCat là một file chạy duy nhất kèm giao diện web. Nó lên lịch backup, nén và mã hóa, đẩy bản sao lên S3, Google Drive, OneDrive hay SFTP, tự kiểm tra toàn vẹn và đưa dữ liệu về khi bạn cần. Chạy trên Linux lẫn Windows, không cần internet.

Phương thức backup

Ba công cụ, chọn theo cỡ database

DumpCat điều khiển mysqldump, mydumper và XtraBackup / MariaBackup. Khi thêm server, nút Test connection cho biết version, datadir, dung lượng từng database và phương thức nào dùng được trên máy đó.

Nơi lưu trữ

Một job, bản sao nằm ở nhiều nơi

Ghi ra ổ local rồi upload, hoặc stream thẳng lên cloud không cần ổ tạm. Mỗi nơi có thể giữ số bản khác nhau, ví dụ local giữ 3 bản còn S3 giữ 30 ngày.

  • Local / NFSRestore nhanh nhất, đặt khác ổ với datadir
  • S3AWS, Cloudflare R2, MinIO, Wasabi, DigitalOcean
  • Google DriveOAuth hoặc Service Account
  • OneDriveKể cả SharePoint
  • FTP / FTPSExplicit hoặc Implicit TLS
  • SFTPMật khẩu hoặc private key
  • WebDAVNextcloud và tương tự
  • Backblaze B2Cùng Azure Blob và Dropbox
  • rcloneHơn 70 backend còn lại

Mất máy chạy DumpCat? Cài bản mới, thêm lại nơi lưu, bấm Import backup catalog là thấy lại toàn bộ backup. Không có DumpCat vẫn restore được bằng age, zstd và mysql.

Kết nối

Database không mở port? Vẫn backup được

Khi server backup không kết nối thẳng được tới MySQL, vì firewall, NAT hay MySQL chỉ nghe trên 127.0.0.1, hãy để chính server database kết nối ra DumpCat. Có hai cách, cả hai đều không cần mở port nào trên server database. Backup, restore và khôi phục theo thời điểm chạy y như kết nối trực tiếp.

Agent HTTPS

Server database cần
Đi ra được DumpCat qua HTTPS
MySQL
Không đổi gì, kể cả khi chỉ nghe trên 127.0.0.1
Cài
sudo ./install.sh --agent --server … --key …
Hợp khi
Không muốn đụng tới mạng hay cấu hình MySQL

WireGuard tích hợp UDP · tắt mặc định

Server database cần
WireGuard chuẩn, đi ra được DumpCat qua UDP 51820
MySQL
Nghe trên địa chỉ VPN, user cho phép từ 10.66.0.1
Cài
Bật trên trang WireGuard, chép dumpcat.conf, systemctl enable --now wg-quick@dumpcat
Hợp khi
Đội đã quen WireGuard, hoặc một gateway dẫn tới cả mạng database

Đường kết nối do server database mở ra; dữ liệu đi hai chiều bên trong nó. Backup vật lý (XtraBackup / MariaBackup) chép datadir nên vẫn cần cài DumpCat ngay trên server database.

Vận hành

Những việc bạn khỏi phải tự viết script

Tất cả có sẵn trong DumpCat và được bật, chỉnh ngay trên giao diện web.

Mã hóa trước khi upload
age (ChaCha20-Poly1305 + scrypt) chạy trên server của bạn, nhà cung cấp cloud không đọc được dữ liệu.
Kiểm tra toàn vẹn
SHA-256 cho từng file. Verify đọc lại, giải mã, giải nén và tìm dòng Dump completed.
Retention kiểu GFS
Giữ N bản, N ngày, bản cuối mỗi ngày, tuần, tháng. Chuỗi incremental chỉ bị xóa cùng bản full gốc.
Restore cẩn thận
Thử giải mã mọi file trước khi DROP database. Restore sang tên mới, hoặc sang server và phiên bản khác (MySQL 8 ↔ MariaDB).
Tài khoản và phân quyền
admin, operator, viewer. 2FA bằng TOTP, API token, nhật ký thao tác, khóa sau nhiều lần đăng nhập sai.
Thông báo
Email, Telegram, Slack, Discord và Webhook ký HMAC, khi lỗi hoặc khi thành công.
Database sau firewall
Agent trên server database tự kết nối ra DumpCat qua HTTPS, hoặc dùng WireGuard tích hợp. Không cần mở port nào tới database.
Tự cập nhật
dumpcat update kiểm tra SHA-256, backup cấu hình, chờ backup đang chạy xong và tự rollback nếu lỗi.

Mã nguồn mở

Miễn phí, mã nguồn mở, dữ liệu vẫn là của bạn

DumpCat phát hành theo giấy phép Apache-2.0. Không cần tài khoản, không license key, không có bản trả phí khóa bớt tính năng: mọi thứ trên trang này đều nằm trong bản bạn tải về.

Giấy phép Apache-2.0
Dùng cho cá nhân hay doanh nghiệp, sửa và phân phối lại đều được. Toàn văn giấy phép nằm trong LICENSE.
Không telemetry
DumpCat không gửi dữ liệu sử dụng đi đâu cả. Việc duy nhất nó tự gọi ra ngoài là mỗi ngày đọc latest.json một lần để báo bản mới, và bạn tắt được trong Settings.
Không qua máy chủ trung gian
Backup, mật khẩu database và khóa mã hóa chỉ đi từ server của bạn tới nơi lưu trữ do bạn chọn.
Bản phát hành có ký
Mỗi bản cập nhật được ký ed25519 và kiểm tra SHA-256 trước khi cài. Muốn tự build thì chỉ cần Go.

Build từ mã nguồn

bash
git clone https://github.com/theweakestharrison/DumpCat.git
cd DumpCat
go build -o dumpcat ./cmd/dumpcat

      Cài đặt

      Chạy được sau một phút

      Một file binary Go, giao diện web nhúng sẵn, không cần runtime. Script cài đặt tạo service và cài luôn các công cụ khớp với version database trên máy.

      bash
      curl -fLO https://downloads.dumpcat.cc/1.3.1/dumpcat-1.3.1-linux.tar.gz
tar xzf dumpcat-1.3.1-linux.tar.gz
cd dumpcat-1.3.1-linux
sudo ./install.sh

      Cài vào /opt/dumpcat, tạo service systemd, cài rclone, MySQL/MariaDB client, mariabackup hoặc XtraBackup đúng version, và mydumper nếu repo có. Tùy chọn: --port 9090, --listen 127.0.0.1, --tls-auto.

      PowerShell (Administrator)
      Invoke-WebRequest https://downloads.dumpcat.cc/1.3.1/dumpcat-1.3.1-windows-amd64.zip -OutFile dumpcat-1.3.1-windows-amd64.zip
Expand-Archive dumpcat-1.3.1-windows-amd64.zip -DestinationPath .
cd dumpcat-1.3.1-windows-amd64
powershell -ExecutionPolicy Bypass -File .\install.ps1

      Chạy PowerShell bằng quyền Administrator. Windows Server 2016+ / Windows 10+ 64-bit, chạy như Windows service. Không có mydumper và XtraBackup cho MySQL; database hàng trăm GB nên chạy DumpCat trên Linux.
