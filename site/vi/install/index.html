Cài DumpCat từng bước

Dành cho người mới: không cần rành Linux hay dòng lệnh. Khoảng năm phút từ lúc tải về tới bản backup đầu tiên.

Server LinuxWindows

Trước khi bắt đầu

  • Một máy để chạy DumpCatTốt nhất là chính server database, chạy Linux hoặc Windows 64-bit. Máy khác cũng được, miễn là kết nối tới được database.
  • Quyền quản trịsudo trên Linux, tài khoản Administrator trên Windows.
  • Một trình duyệt webDumpCat dùng qua trình duyệt: không phải cài gì lên máy tính của bạn.

Muốn xem trước? Xem giao diện bạn có sau khi cài, với dữ liệu mẫu, ngay trong trình duyệt.

Linux

Cài trên server Linux

  1. Mở cửa sổ dòng lệnh trên server

    Trên máy tính của bạn, mở cửa sổ dòng lệnh (Windows: bấm Start, gõ PowerShell; macOS: ứng dụng Terminal) rồi kết nối vào server:

    Terminal
    ssh user@ip-server

    Thay user và ip-server bằng tên đăng nhập và địa chỉ mà nhà cung cấp server đưa cho bạn. Lần đầu sẽ có câu hỏi: gõ yes. Nhiều nhà cung cấp còn có nút Console trên trang quản lý, mở cùng cửa sổ dòng lệnh đó ngay trong trình duyệt.

  2. Dán lệnh này rồi bấm Enter

    bash
    curl -fsSL https://dumpcat.cc/install.sh | sudo sh

    Nếu được hỏi mật khẩu, gõ mật khẩu của bạn: chữ không hiện ra khi gõ, đó là bình thường. Lệnh này tải DumpCat bản mới nhất, kiểm tra file, cài thành service tự chạy cùng server và cài luôn công cụ backup khớp với database của bạn. Mất khoảng một hai phút.

  3. Ghi lại địa chỉ và mã thiết lập

    Cuối cùng, bộ cài in ra dạng như sau:

    DumpCat is running: http://<ip-server>:6369/
No account yet: open the address above and create the admin account.
  The setup page asks for this one-time setup token:  XXXX-XXXX-XXXX-XXXX-XXXX-XXXX

    Mất mã? Chạy sudo dumpcat setup-token để xem lại.

  4. Mở địa chỉ đó trên trình duyệt

    Rồi làm tiếp phần Mở DumpCat lần đầu bên dưới.

    Trang không mở được? Port 6369 đang bị chặn. Mở port trên server bằng sudo ufw allow 6369/tcp (hoặc firewall-cmd --permanent --add-port=6369/tcp && firewall-cmd --reload), với server cloud thì mở thêm trong firewall hoặc security group của nhà cung cấp. Nếu được, chỉ mở cho IP của bạn.

Windows

Cài trên Windows

  1. Tải DumpCat cho Windows

    Tải file .zip

  2. Giải nén

    Chuột phải vào file vừa tải, chọn Extract All… rồi Extract. Một thư mục sẽ mở ra.

  3. Bấm đúp vào Install DumpCat

    Windows hỏi Do you want to allow this app to make changes to your device?: chọn Yes.

    Nếu Windows hiện Windows protected your PC, bấm More info rồi Run anyway. DumpCat được cài thành Windows service, nên vẫn chạy sau khi bạn đóng cửa sổ và tự chạy khi bật máy.

  4. Trình duyệt tự mở DumpCat

    Cửa sổ cài đặt hiện mã thiết lập: giữ lại, trang đầu tiên sẽ hỏi mã này. Địa chỉ trên máy này là http://localhost:6369. Rồi làm tiếp phần Mở DumpCat lần đầu.

Quen dùng PowerShell? Mở PowerShell bằng quyền Administrator (chuột phải vào Start, chọn Terminal (Admin)) rồi chạy:
PowerShell (Administrator)
irm https://dumpcat.cc/install.ps1 | iex

Sau khi cài

Mở DumpCat lần đầu

  1. Tạo tài khoản admin

    Dán mã thiết lập, chọn tên đăng nhập và mật khẩu. Đăng nhập hai lớp có thể bật sau, trong Profile & security.

  2. Thêm database

    Database servers → Add server. Khi DumpCat chạy ngay trên server database, host là 127.0.0.1, port 3306 (PostgreSQL: chọn engine PostgreSQL, port 5432). Nhập user và mật khẩu database rồi bấm Test connection: DumpCat hiện các database nó thấy và quyền nào còn thiếu.

  3. Chọn nơi lưu backup

    Storage → Add storage. Bắt đầu đơn giản nhất là một thư mục trên máy này; Google Drive, OneDrive, S3, SFTP và nhiều nơi khác thêm theo cùng cách. Bấm Test.

  4. Tạo backup job

    Backup jobs → New job. Chọn database, lịch chạy và nơi lưu, rồi bấm Save & run now. Bản backup đầu tiên chạy ngay và được đọc lại để kiểm tra.

Chi tiết từng màn hình: xem hướng dẫn đầy đủ, cũng có trong mọi gói tải về (docs/manual.vi.md).

Đã tải file về?

Cài từ gói đã tải về

Gói nào cũng có file START-HERE.txt ghi các bước này.

Windows (.zip)

Giải nén rồi bấm đúp Install DumpCat, như các bước cho Windows.

Linux (.tar.gz)

File phải nằm trên server. Cách dễ nhất là chạy lệnh một dòng ngay trên server, lệnh đó tải đúng file này. Hoặc chép file lên server (ví dụ bằng scp hay WinSCP) rồi chạy trên server:

bash
tar xzf dumpcat-*-linux.tar.gz
cd dumpcat-*-linux
sudo ./install.sh

Chỉ muốn chạy thử, không cài?

Chạy thẳng chương trình trong thư mục đã giải nén, rồi mở http://localhost:6369. Mã thiết lập in ngay trong cửa sổ; bấm Ctrl+C để dừng.

Linux
./dumpcat-linux-amd64 serve -data-dir ./data
Windows (PowerShell, trong thư mục)
.\dumpcat.exe serve -data-dir .\data

Câu hỏi và sự cố

Trình duyệt không mở được trang

Kiểm tra DumpCat có đang chạy: systemctl status dumpcat trên Linux, service DumpCat trong services.msc trên Windows. Từ máy khác thì port 6369 phải được mở: trên Linux sudo ufw allow 6369/tcp, trên Windows chạy lại bộ cài với -OpenFirewall, và với server cloud thì mở thêm trong firewall của nhà cung cấp.

Tôi làm mất mã thiết lập

Linux: sudo dumpcat setup-token. Windows, trong PowerShell chạy bằng quyền Administrator: & "C:\Program Files\DumpCat\dumpcat.exe" setup-token -config "C:\ProgramData\DumpCat\dumpcat.env". Mã dùng được cho tới khi có tài khoản đầu tiên.

Dùng port khác 6369

Linux: curl -fsSL https://dumpcat.cc/install.sh | sudo sh -s -- --port 9090. Windows: trong thư mục đã giải nén, mở PowerShell bằng quyền Administrator, chạy powershell -ExecutionPolicy Bypass -File .\install.ps1 -Port 9090.

Cập nhật lên bản mới

Mở trang System trong DumpCat: khi có bản mới, trang này báo và cài bằng một cú bấm, sau khi kiểm tra chữ ký. Chạy lại lệnh cài cũng cho kết quả tương tự.

Gỡ cài đặt

Linux: curl -fsSL https://dumpcat.cc/install.sh | sudo sh -s -- --uninstall (thêm --purge để xóa luôn cấu hình và danh mục backup của DumpCat trong /var/lib/dumpcat và /etc/dumpcat). Windows: trong thư mục đã giải nén, mở PowerShell bằng quyền Administrator, chạy powershell -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall.

Database nằm trên server khác, sau firewall

Cài DumpCat ở đâu cũng được, rồi để server database tự kết nối ra: bằng DumpCat agent nhỏ gọn hoặc WireGuard tích hợp. Xem ba cách kết nối.
