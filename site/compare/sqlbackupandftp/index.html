DumpCat vs SQLBackupAndFTP

SQLBackupAndFTP, from Pranas.NET, is a long-standing Windows app that backs up SQL Server, MySQL, MariaDB and PostgreSQL to local and cloud storage. DumpCat is a free, open-source MySQL and MariaDB backup manager for Linux and Windows. Here is how they compare.

Choose SQLBackupAndFTP if

  • You are on Windows and also back up SQL Server or PostgreSQL, and want one tool for all of them.
  • You prefer a one-time licence and a desktop app with guided setup wizards for cloud storage.
  • You want vendor support with a paid service plan.

Choose DumpCat if

  • Your MySQL or MariaDB server runs on Linux: DumpCat runs natively on Linux (amd64, arm64) and on Windows.
  • You need real point-in-time recovery: continuous binlog archiving and restore to a second or just before a GTID.
  • Your databases are large: parallel mydumper and hot physical backups with XtraBackup / MariaBackup.
  • You want S3, encryption and every notification channel without a paid tier: DumpCat is free and open source.

Switching from SQLBackupAndFTP

  1. Install DumpCat on the database server (Linux or Windows).
  2. Add the storage you use today (Google Drive, S3, SFTP…) to DumpCat, in a new folder.
  3. Recreate each job, and turn on binlog archiving where you used SQLBackupAndFTP's incremental backups.
  4. Run each job once and check the integrity result; keep the old backups until DumpCat's retention covers the same period.
