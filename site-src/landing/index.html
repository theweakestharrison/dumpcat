Backup không khóa database. Khôi phục đến đúng giây bạn cần.

DumpCat là một file chạy duy nhất kèm giao diện web. Nó lên lịch backup, nén và mã hóa, đẩy bản sao lên S3, Google Drive, OneDrive hay SFTP, tự kiểm tra toàn vẹn và đưa dữ liệu về khi bạn cần. Chạy trên Linux lẫn Windows, không cần internet.

Cài đặt

Chạy được sau một phút

Một lệnh trên Linux, tải về và bấm đúp trên Windows. Bộ cài tạo service tự chạy cùng máy và cài luôn công cụ backup khớp với version database; giao diện web có sẵn trong một file duy nhất.

Trên server Linux, dán lệnh này rồi bấm Enter:

bash
curl -fsSL https://dumpcat.cc/install.sh | sudo sh

Lệnh tải bản mới nhất, kiểm tra checksum rồi cài vào /opt/dumpcat thành service systemd, kèm rclone, MySQL/MariaDB client, mariabackup hoặc XtraBackup đúng version, và mydumper nếu repo có; --postgres 16 cài thêm công cụ client PostgreSQL 16. Tùy chọn đặt sau sh -s --: --port 9090, --listen 127.0.0.1, --tls-auto.

  1. Tải file .zip Tải cho Windows 1.8.0
  2. Giải nén: chuột phải vào file, chọn Extract All.
  3. Bấm đúp Install DumpCat rồi chọn Yes. Trình duyệt tự mở DumpCat, cửa sổ cài đặt hiện mã thiết lập.

Windows 10 / 11 hoặc Windows Server 2016+ 64-bit, chạy như Windows service. Quen PowerShell? Chạy irm https://dumpcat.cc/install.ps1 | iex trong PowerShell (Administrator). Không có mydumper và XtraBackup cho MySQL; database hàng trăm GB nên chạy DumpCat trên Linux.

Chưa quen dòng lệnh? Xem hướng dẫn từng bước, có cả cách xử lý khi gặp lỗi.

AI-friendly · MCP

Để trợ lý AI thiết lập và trông backup, mà không phải giao chìa khóa

DumpCat là một MCP server. Kết nối Claude Code, Claude Desktop hay MCP client khác bằng một API token rồi nói bằng lời thường: trợ lý thêm server và storage, tạo job và diễn tập restore, xem backup nào lỗi hay quá hạn, đọc log và giải thích vì sao. Mật khẩu và khóa thì bạn tự nhập trên giao diện web. Agent AI khác đọc tài liệu API bằng Markdown do chính server của bạn viết ra.

Trợ lý AI được làm gì

  • XemToken chỉ xem, mặc địnhTổng quan và cảnh báo, job, backup, lỗi và log, việc lưu binlog / WAL, kết quả restore và diễn tập, xem trước một lần khôi phục theo thời điểm.
  • Khởi chạyToken toàn quyền, operator hoặc adminChạy backup, verify một bản backup, chạy diễn tập restore. Client AI hỏi bạn trước mỗi lần.
  • Thiết lậpToken ManageThêm server và storage, tạo và sửa job, diễn tập restore. Mật khẩu, khóa và passphrase không bao giờ đi qua trợ lý: nó đưa bạn link để tự nhập.
  • Không bao giờ qua MCPVới bất kỳ token nàoRestore, xóa và cài đặt của DumpCat. Không có tùy chọn nào bật chúng lên: những việc này chỉ làm trên giao diện web.

Câu trả lời không bao giờ chứa mật khẩu, khóa hay token, và không công cụ nào nhận chúng; thông tin đăng nhập lẫn trong lỗi và log đều bị che. Mỗi lần gọi đi qua REST API bằng token của bạn, nên được kiểm tra quyền như mọi request và ghi vào nhật ký thao tác.

Kết nối trong một phút

  1. Tạo tokenTrang API & MCP trong DumpCat, nút New token: Read-only (mặc định) chỉ xem, Full chạy được backup, Manage thiết lập được backup.
  2. Chép cấu hìnhTrang đó điền sẵn địa chỉ server và token vào lệnh cho Claude Code, file cấu hình cho Claude Desktop và các client khác.
  3. Bấm Test rồi hỏiTest MCP connection cho biết tài khoản, quyền và các công cụ mà trợ lý sẽ nhận được.
bash
claude mcp add --transport http dumpcat \
  https://backup.example.com/api/mcp \
  --header "Authorization: Bearer mv_…"

Thay địa chỉ và token bằng của bạn, hoặc chép lệnh đã điền sẵn trên trang API & MCP. Muốn dùng chung trong một project mà không lộ token: trang đó có sẵn file .mcp.json lấy token từ biến môi trường.

claude_desktop_config.json
{
  "mcpServers": {
    "dumpcat": {
      "command": "C:\\Program Files\\DumpCat\\dumpcat.exe",
      "args": ["mcp"],
      "env": {
        "DUMPCAT_MCP_URL": "https://backup.example.com",
        "DUMPCAT_MCP_TOKEN": "mv_…"
      }
    }
  }
}

Mở Settings → Developer → Edit Config, dán vào rồi khởi động lại Claude Desktop. dumpcat mcp là cầu nối stdio nhỏ chạy trên máy có Claude Desktop; trên Linux, command là đường dẫn tới file dumpcat, còn macOS thì tự build bằng Go.

json
{
  "mcpServers": {
    "dumpcat": {
      "url": "https://backup.example.com/api/mcp",
      "headers": { "Authorization": "Bearer mv_…" }
    }
  }
}

Endpoint /api/mcp (streamable HTTP) nằm sẵn trong DumpCat, không cài thêm gì. Client chỉ biết chạy lệnh local thì dùng dumpcat mcp, với DUMPCAT_MCP_URL và DUMPCAT_MCP_TOKEN trong biến môi trường.

bash
curl -H "Authorization: Bearer $TOKEN" \
  https://backup.example.com/api/docs.md

/api/docs.md là toàn bộ tài liệu API bằng Markdown, do chính server viết ra nên luôn khớp phiên bản bạn chạy: xác thực, quy ước, ví dụ curl và từng route kèm quyền cần có. Để agent tự đọc rồi gọi REST API, hoặc dán vào khung chat (API & MCP → Copy Markdown). /api/mcp/tools liệt kê các công cụ MCP dạng JSON.

Phương thức backup

Đúng công cụ cho từng loại và cỡ database

Với MySQL và MariaDB, DumpCat điều khiển mysqldump, mydumper và XtraBackup / MariaBackup. Khi thêm server, nút Test connection cho biết version, datadir, dung lượng từng database và phương thức nào dùng được trên máy đó.

PostgreSQL 10 trở lên: pg_dump cho từng database, dump và restore các bảng song song, sang tên mới hoặc sang server khác; pg_basebackup cho cả cluster qua kết nối replication, kèm lưu WAL liên tục để khôi phục về một thời điểm, một restore point hoặc một vị trí WAL.

SQL Server 2012 trở lên, trên Windows, Linux và container: backup full và differential bằng chính BACKUP DATABASE của SQL Server (không cần cài client), restore sang tên mới hoặc sang server khác, diễn tập restore với DBCC CHECKDB, và log backup theo lịch để khôi phục về một thời điểm, một marked transaction hoặc một LSN. SQL Server ghi backup ngay trên máy của nó: DumpCat đọc file qua một thư mục chia sẻ, hoặc agent trên máy đó chuyển file về mà không cần chia sẻ gì.

Kết nối

Database không mở port? Vẫn backup được

Khi server backup không kết nối thẳng được tới database, vì firewall, NAT hay database chỉ nghe trên 127.0.0.1, hãy để chính server database kết nối ra DumpCat. Có hai cách, cả hai đều không cần mở port nào trên server database. Backup, restore và khôi phục theo thời điểm chạy y như kết nối trực tiếp.

Hợp khi
Đội đã quen WireGuard, hoặc một gateway dẫn tới cả mạng database

Đường kết nối do server database mở ra; dữ liệu đi hai chiều bên trong nó. Backup vật lý (XtraBackup / MariaBackup) chạy được qua agent khi agent bật --allow-physical; qua WireGuard thì vẫn cần cài DumpCat ngay trên server database. File backup của SQL Server cũng đi qua agent khi agent bật --allow-mssql-dir, không cần thư mục chia sẻ.

Vận hành

Những việc bạn khỏi phải tự viết script

Tất cả có sẵn trong DumpCat và được bật, chỉnh ngay trên giao diện web.

Mã hóa và kiểm tra
age (ChaCha20-Poly1305 + scrypt) mã hóa ngay trên server trước khi upload. SHA-256 cho từng file, và mỗi bản backup được đọc lại, giải mã, giải nén ngay sau khi ghi.
Retention kiểu GFS
Giữ N bản, N ngày, bản cuối mỗi ngày, tuần, tháng. Chuỗi incremental chỉ bị xóa cùng bản full gốc.
Restore cẩn thận
Thử giải mã mọi file trước khi DROP database. Restore sang tên mới, hoặc sang server và phiên bản khác (MySQL 8 ↔ MariaDB, PostgreSQL 15 → 16).
Nhóm và đăng nhập một lần
Bao nhiêu user cũng được, với vai trò admin, operator hoặc viewer. Đăng nhập bằng Google, Microsoft Entra ID hay mọi nhà cung cấp OpenID Connect, 2FA bằng TOTP, API token và nhật ký thao tác.
Tên và logo của bạn
White-label: tên và logo riêng thay chữ DumpCat trên giao diện web, trang đăng nhập, tab trình duyệt và mọi thông báo.
Thông báo
Email, Telegram, Slack, Discord và Webhook ký HMAC, khi lỗi hoặc khi thành công.
Database sau firewall
Agent trên server database tự kết nối ra DumpCat qua HTTPS, hoặc dùng WireGuard tích hợp. Không cần mở port nào tới database.
Cập nhật OTA
Bật tự động cài là bản mới có chữ ký từ máy chủ build của DumpCat tự về trong khung giờ bạn chọn. Nó chờ backup đang chạy xong, backup database của chính nó và tự rollback nếu có lỗi. Không phải build lại gì.

Mã nguồn mở

Miễn phí, mã nguồn mở, dữ liệu vẫn là của bạn

DumpCat phát hành theo giấy phép Apache-2.0. Không cần tài khoản, không license key, không có bản trả phí khóa bớt tính năng: mọi thứ trên trang này đều nằm trong bản bạn tải về.

Giấy phép Apache-2.0
Dùng cho cá nhân hay doanh nghiệp, sửa và phân phối lại đều được. Toàn văn giấy phép nằm trong LICENSE.
Không telemetry
DumpCat không gửi dữ liệu sử dụng đi đâu cả. Việc duy nhất nó tự gọi ra ngoài là đọc latest.json để báo bản mới và, khi bạn bật tự động cài, tải bản đó về. Cả hai đều tắt được trong Settings.
Không qua máy chủ trung gian
Backup, mật khẩu database và khóa mã hóa chỉ đi từ server của bạn tới nơi lưu trữ do bạn chọn.
Bản phát hành có ký, không phải tự build
Bản chính thức đến từ máy chủ build của DumpCat, được ký ed25519 và kiểm tra SHA-256 trước khi cài. Tự build là tùy bạn, chỉ cần Go.
