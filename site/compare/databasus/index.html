DumpCat vs Databasus

Databasus, formerly Postgresus, is a popular open-source backup web app that grew from PostgreSQL to MySQL, MariaDB and other engines. DumpCat focuses on MySQL and MariaDB only. Both are Apache-2.0 and self-hosted; here is where they differ.

Choose Databasus if

  • You back up PostgreSQL as well, where Databasus also offers physical backups and point-in-time recovery.
  • You run on Kubernetes or Docker and want a Helm chart.
  • You want automatic restore verification in throwaway containers, or team workspaces with Google / GitHub sign-in.

Choose DumpCat if

  • You need point-in-time recovery for MySQL or MariaDB: DumpCat archives binlogs and restores to a second or just before a GTID.
  • Your MySQL databases are large: parallel mydumper and hot physical backups with XtraBackup / MariaBackup, including incrementals.
  • You do not want Docker: DumpCat is one binary, installed as a systemd or native Windows service.
  • You want a tool built only around MySQL and MariaDB, with restores into a new database name and checks before anything is dropped.
