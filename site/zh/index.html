AI让 Claude 帮你配置和检查备份

开源 · MySQL、MariaDB、PostgreSQL 和 SQL Server 的备份与恢复

备份从不锁库。恢复精确到秒。

DumpCat 是一个自带 Web 界面的单文件程序。它按计划执行备份，压缩并加密，把副本传到 S3、Google Drive、OneDrive 或 SFTP，校验备份，并在你需要时把数据恢复回来。支持 Linux 和 Windows，可完全离线运行。

安装

一分钟跑起来

Linux 上只需一条命令，Windows 上下载后双击即可。安装程序会注册一个开机自启的服务，并安装与你的数据库版本匹配的备份工具；Web 界面已打包在同一个文件里。

在 Linux 服务器上粘贴这条命令并按回车：

bash
curl -fsSL https://dumpcat.cc/install.sh | sudo sh

它会下载最新版本、核对校验和，并以 systemd 服务的形式安装到 /opt/dumpcat，同时安装 rclone、MySQL/MariaDB 客户端、对应版本的 mariabackup 或 XtraBackup，软件源里有 mydumper 时也会一并安装；--postgres 16 会额外安装 PostgreSQL 16 客户端工具。选项写在 sh -s -- 之后：--port 9090、--listen 127.0.0.1、--tls-auto。

  1. 下载 .zip 文件 下载 Windows 版 1.8.0
  2. 解压：右键点击该文件，选择 Extract All（全部解压缩）。
  3. 双击 Install DumpCat，在提示中选择 Yes（是）。浏览器会打开 DumpCat；安装窗口中会显示初始化令牌（setup token）。

支持 Windows 10 / 11 或 Windows Server 2016+ 64 位，以 Windows 服务运行。更习惯 PowerShell？在 PowerShell（管理员）中运行 irm https://dumpcat.cc/install.ps1 | iex。Windows 版不提供 MySQL 的 mydumper 和 XtraBackup；数百 GB 的数据库请在 Linux 上运行 DumpCat。

刚接触命令行？按照分步指南操作（英文），里面还有常见问题的解决方法。

安装之后

  1. 打开 http://<server-ip>:6369使用安装程序打印的一次性初始化令牌创建管理员账号（再次显示：dumpcat setup-token）。
  2. 添加数据库服务器Test connection 会列出缺少的权限以及可用的备份方式。
  3. 添加存储Test 会写入、读取并删除一个测试文件。
  4. 创建备份任务选择计划、加密、存储和保留策略，然后点击 Save & run now。

AI 友好 · MCP

让 AI 助手替你配置和盯着备份，却不必交出钥匙

DumpCat 本身就是一个 MCP 服务器。用 API 令牌接入 Claude Code、Claude Desktop 或其他 MCP 客户端，然后用日常语言提出要求：助手会添加服务器和存储，创建备份任务和恢复演练，查出哪些备份失败或逾期，读取日志并告诉你原因。密码和密钥则由你自己在 Web 界面中输入。其他 AI Agent 可以阅读你的服务器专门为它们生成的 Markdown 格式 API 参考文档。

AI 助手能做什么

  • 查看只读令牌，默认概览和告警、任务、备份、错误和日志、binlog / WAL 归档、恢复和演练结果、时间点恢复预览。
  • 启动完全权限令牌，operator 或 admin运行备份、校验备份、启动恢复演练。每次执行前，AI 客户端都会先征求你的同意。
  • 配置Manage 令牌添加服务器和存储，创建和修改备份任务及恢复演练。密码、密钥和口令从不经过助手：它会给你一个链接，由你自己输入。
  • 永远不经过 MCP无论使用什么令牌恢复、删除和 DumpCat 的系统设置。没有任何选项能开启它们：这些操作只在 Web 界面中进行。

回答中绝不包含密码、密钥或令牌，也没有工具会接收它们；错误和日志中出现的凭据会被遮盖。每次调用都以你的令牌经由 REST API 执行，因此会像其他请求一样检查权限，并写入审计日志。

一分钟完成连接

  1. 创建令牌在 DumpCat 的 API & MCP 页面点击 New token：Read-only（默认）只能查看，Full 还能运行备份，Manage 还能配置备份。
  2. 复制配置该页面会把服务器地址和令牌填入 Claude Code 命令、Claude Desktop 配置以及其他客户端的配置中。
  3. 测试后开始提问Test MCP connection 会显示助手将获得的账户、权限和工具。
bash
claude mcp add --transport http dumpcat \
  https://backup.example.com/api/mcp \
  --header "Authorization: Bearer mv_…"

换成你自己的地址和令牌，或直接复制 API & MCP 页面上已填好的命令。想在项目中共享而不暴露令牌，该页面还提供从环境变量读取令牌的 .mcp.json。

claude_desktop_config.json
{
  "mcpServers": {
    "dumpcat": {
      "command": "C:\\Program Files\\DumpCat\\dumpcat.exe",
      "args": ["mcp"],
      "env": {
        "DUMPCAT_MCP_URL": "https://backup.example.com",
        "DUMPCAT_MCP_TOKEN": "mv_…"
      }
    }
  }
}

打开 Settings → Developer → Edit Config，粘贴后重启 Claude Desktop。dumpcat mcp 是一个小型 stdio 桥接程序，运行在装有 Claude Desktop 的电脑上；在 Linux 上，command 填 dumpcat 可执行文件的路径，macOS 则需用 Go 自行编译。

json
{
  "mcpServers": {
    "dumpcat": {
      "url": "https://backup.example.com/api/mcp",
      "headers": { "Authorization": "Bearer mv_…" }
    }
  }
}

/api/mcp 端点（streamable HTTP）是 DumpCat 的一部分，无需额外安装。只能启动本地命令的客户端使用 dumpcat mcp，并在环境变量中设置 DUMPCAT_MCP_URL 和 DUMPCAT_MCP_TOKEN。

bash
curl -H "Authorization: Bearer $TOKEN" \
  https://backup.example.com/api/docs.md

/api/docs.md 是完整的 Markdown 格式 API 参考，由服务器自己生成，因此始终与你运行的版本一致：认证、约定、curl 示例，以及每个路由所需的权限。让 Agent 自己读取后调用 REST API，或粘贴到聊天中（API & MCP → Copy Markdown）。/api/mcp/tools 以 JSON 列出 MCP 工具。

备份方式

不同数据库、不同规模，各有合适的工具

对于 MySQL 和 MariaDB，DumpCat 可调用 mysqldump、mydumper 以及 XtraBackup / MariaBackup。添加服务器时，Test connection 会显示版本、datadir、每个数据库的大小，以及这台机器上可用的备份方式。

mysqldump逻辑备份mydumper逻辑备份，并行XtraBackup / MariaBackup物理备份，热备
会锁库吗？InnoDB 不锁，靠的是 --single-transaction为同步各线程加几毫秒全局锁，之后不再加锁不锁 InnoDB；结束时有极短暂的备份锁
备份速度每个数据库 1 个线程，多个数据库并行多线程，表按行分块最快：多线程复制文件
恢复速度最慢快：并行，加载完成后再建索引非常快：复制文件 + prepare
增量备份不支持不支持支持
单库恢复、改名支持支持不支持，只能恢复整个实例
最适合20–50 GB 以下的数据库需要逐个恢复的大型数据库100 GB 到数 TB，要求低 RTO

PostgreSQL 10 及以上：pg_dump 按数据库备份，表并行导出和恢复，可恢复为新名称或恢复到另一台服务器；pg_basebackup 通过复制连接备份整个集群，配合持续 WAL 归档，可恢复到某个时间、某个还原点或某个 WAL 位置。

SQL Server 2012 及以上（Windows、Linux 和容器）：用 BACKUP DATABASE 做原生完整备份和差异备份（无需客户端工具），可恢复为新名称或恢复到另一台服务器，用 DBCC CHECKDB 做恢复演练，并按计划做日志备份，可恢复到某个时间、某个标记事务或某个 LSN。SQL Server 把备份写在自己的主机上：DumpCat 从共享文件夹读取，或由该主机上的 Agent 传输文件，无需任何共享。

可以先写入本地磁盘再上传，也可以不占用临时磁盘、直接流式上传到云端。每个存储各自设定保留份数，例如本地保留 3 份备份，S3 上保留 30 天。

运行 DumpCat 的机器没了？重新装一份，再次添加存储，点击 Import backup catalog：所有备份都会重新列出来。即使没有 DumpCat，也能用 age、zstd 加上 mysql、pg_restore 或 SQL Server 的 RESTORE DATABASE 完成恢复。

网络连接

数据库没开端口？照样能备份。

当备份服务器无法直接连上数据库时（比如有防火墙、NAT，或数据库只监听 127.0.0.1），可以反过来让数据库主机主动连接 DumpCat。有两种方式，都不需要在数据库主机上开放端口。备份、恢复和时间点恢复都与直连时完全一样。

Agent HTTPS

数据库主机需要
能通过出站 HTTPS 访问 DumpCat
数据库
无需改动，即使只监听 127.0.0.1
安装
sudo ./install.sh --agent --server … --key …
适合
不想改动网络和 MySQL 配置的场景

内置 WireGuard UDP · 默认关闭

数据库主机需要
标准 WireGuard，出站 UDP 51820 到 DumpCat
数据库
监听 VPN 地址，数据库账号允许来自 10.66.0.1 的连接
安装
在 WireGuard 页面启用，复制 dumpcat.conf，执行 systemctl enable --now wg-quick@dumpcat
适合
已在使用 WireGuard 的团队，或用作通往整个数据库网段的网关

连接由数据库主机发起，数据在连接内双向传输。物理备份（XtraBackup / MariaBackup）可以通过以 --allow-physical 启动的 Agent 进行；走 WireGuard 时，仍需在数据库主机上安装 DumpCat。SQL Server 的备份文件也可以通过以 --allow-mssql-dir 启动的 Agent 传输，无需共享文件夹。

运维

那些本该自己写脚本的活，都替你做好了

全部内置于 DumpCat，在 Web 界面中开启和调整。

上传前加密
age（ChaCha20-Poly1305 + scrypt）在你自己的服务器上运行，云服务商无法读取你的数据。
完整性校验
每个文件都有 SHA-256。校验时会重新读取、解密、解压，并检查是否有 Dump completed 这一行。
GFS 保留策略
保留 N 份备份、N 天，或每天、每周、每月的最后一份。增量链只会随其全量备份一起删除。
稳妥的恢复
删除任何数据库之前，先对每个文件做试解密。可以恢复为新名称，或恢复到另一台服务器、另一个版本（MySQL 8 ↔ MariaDB，PostgreSQL 15 → 16）。
账号与角色
admin、operator、viewer 三种角色。支持 TOTP 双因素认证、API 令牌、审计日志，多次登录失败后锁定账号。
通知
邮件、Telegram、Slack、Discord 以及 HMAC 签名的 Webhook，可在失败或成功时发送。
防火墙后的数据库
数据库主机上的 Agent 通过 HTTPS 主动连接 DumpCat，或者让主机加入内置的 WireGuard。无需为数据库开放任何端口。
自我更新
dumpcat update 会校验 SHA-256、备份配置、等待正在运行的备份完成，失败时自动回滚。

开源

免费、开源，数据始终归你所有

DumpCat 以 Apache-2.0 许可证发布。无需注册账号，无需许可证密钥，也没有把功能藏起来的付费版：本页介绍的一切，都包含在你下载的版本里。

Apache-2.0 许可证
个人和公司均可使用，可以修改和再分发。完整条款见 LICENSE。
无遥测
DumpCat 不向任何地方发送使用数据。它唯一主动发起的请求，是每天读取一次 latest.json 以提示新版本，而且可以在设置（Settings）中关闭。
没有中间商
备份、数据库密码和加密密钥只会从你的服务器传到你选择的存储。
签名发布
每次更新都使用 ed25519 签名，安装前会校验 SHA-256。自行构建只需要 Go。
