DumpCat vs SnapShooter

SnapShooter is a hosted backup service that DigitalOcean acquired in January 2023; the last product update listed in its docs is from September 2024. DumpCat is a free, open-source backup manager that runs on your own server. Here is how they compare for MySQL and MariaDB.

Choose SnapShooter if

  • You are on DigitalOcean and also want Droplet and volume snapshots in the same place.
  • One small daily backup is enough, and the free plan covers it.
  • You want automatic restores without running anything yourself.

Choose DumpCat if

  • You want a project that is open source and does not depend on one vendor's roadmap.
  • You need storage beyond S3: Google Drive, OneDrive, SFTP, FTP, WebDAV or local disk.
  • You want full point-in-time recovery to a second or a GTID, plus hot physical backups for large databases.
  • You want backups to run without any third-party service in the loop.

Switching from SnapShooter

  1. Install DumpCat on the database server.
  2. Add the same S3 bucket (in a new folder) or any other storage to DumpCat.
  3. Recreate each job, turn on binlog archiving if you used SnapShooter's binlog backups, and run it once.
  4. Keep the SnapShooter backups until DumpCat's retention covers the same period.
