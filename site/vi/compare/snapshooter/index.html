DumpCat vs SnapShooter

SnapShooter là dịch vụ backup trực tuyến được DigitalOcean mua lại vào tháng 1/2023; lần cập nhật sản phẩm gần nhất trong tài liệu của họ là tháng 9/2024. DumpCat là công cụ quản lý backup miễn phí, mã nguồn mở, chạy trên server của bạn. Dưới đây là khác biệt khi dùng cho MySQL và MariaDB.

Chọn SnapShooter nếu

  • Bạn dùng DigitalOcean và muốn chụp snapshot Droplet, volume ở cùng một chỗ.
  • Một bản backup nhỏ mỗi ngày là đủ, và gói miễn phí đáp ứng được.
  • Bạn muốn khôi phục tự động mà không phải tự chạy gì.

Chọn DumpCat nếu

  • Bạn muốn một dự án mã nguồn mở, không phụ thuộc lộ trình của một nhà cung cấp.
  • Bạn cần lưu ra nơi khác ngoài S3: Google Drive, OneDrive, SFTP, FTP, WebDAV hay ổ local.
  • Bạn muốn khôi phục theo thời điểm đến từng giây hoặc GTID, cùng backup vật lý nóng cho database lớn.
  • Bạn muốn backup chạy mà không phụ thuộc dịch vụ của bên thứ ba nào.

Chuyển từ SnapShooter sang DumpCat

  1. Cài DumpCat trên server database.
  2. Thêm cùng bucket S3 (trong thư mục mới) hoặc storage khác vào DumpCat.
  3. Tạo lại từng job, bật lưu binlog nếu bạn đang dùng backup binlog của SnapShooter, rồi chạy thử một lần.
  4. Giữ các bản backup của SnapShooter cho tới khi retention của DumpCat phủ được cùng khoảng thời gian.

So sánh khác

  • DumpCat vs SQLBackupAndFTPỨng dụng backup trên Windows cho SQL Server, MySQL, MariaDB và PostgreSQL, bản quyền theo máy.
  • DumpCat vs SimpleBackupsDịch vụ trực tuyến backup server, database và storage, từ gói miễn phí đến $299/tháng.
  • DumpCat vs DatabasusỨng dụng web backup nhiều loại database, mã nguồn mở (trước là Postgresus); với MySQL chỉ backup logical.
  • DumpCat vs SqlBakDịch vụ backup dùng agent, của nhà làm SQLBackupAndFTP, tính phí theo server.
  • DumpCat vs AutoMySQLBackupScript cron kinh điển, xoay vòng theo ngày / tuần / tháng; dự án gốc dừng từ 2011.
  • DumpCat vs Percona XtraBackupEngine backup vật lý nóng mã nguồn mở. DumpCat chạy nó giúp bạn, kèm lịch, nơi lưu và khôi phục.
  • DumpCat vs MySQL Enterprise BackupCông cụ backup vật lý thương mại của Oracle, nằm trong MySQL Enterprise Edition.
  • DumpCat vs NavicatPhần mềm quản trị database trả phí phổ biến; backup là tính năng phụ, lưu local, chạy theo lịch.
  • DumpCat vs OttomatikDịch vụ lên lịch chạy mysqldump trên server của bạn qua SSH, từ $14/tháng.
  • DumpCat vs BackupSheepTừng là SaaS, nay là bản beta mã nguồn mở tự host cho database, snapshot cloud và WordPress.
