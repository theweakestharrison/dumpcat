DumpCat vs MySQL Enterprise Backup

MySQL Enterprise Backup (mysqlbackup) is Oracle's commercial physical backup tool, included with MySQL Enterprise Edition. DumpCat is a free, open-source backup manager that schedules XtraBackup / MariaBackup and logical dumps from a web UI. Here is how they compare.

Choose MySQL Enterprise Backup if

  • You run Oracle MySQL with an Enterprise subscription and want Oracle support for backups too.
  • You need table-level restore from a physical backup, differential backups or tape via SBT.
  • You are on Oracle Cloud (OCI) and want native integration.

Choose DumpCat if

  • You want it free: DumpCat is open source, with no subscription.
  • You run MariaDB or Percona Server as well as MySQL.
  • You want schedules, retention, alerts and restores in a web UI instead of cron and runbooks.
  • You want point-in-time recovery to a second or a GTID from the UI, with binlogs archived continuously.
